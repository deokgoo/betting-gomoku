# Betting Gomoku — 서바이벌 배팅 오목

칩을 걸고 착수권을 거머쥔다. 다섯 줄이 완성되면 생존이다.

## 플레이

- **VS AI** — AI는 보드의 위협도(열린 3·4목, 승리/차단 기회)를 휴리스틱으로 평가해 중요한 턴에는 과감하게 베팅하고 평이한 턴에는 칩을 아낍니다.
- **2 PLAYER** — 같은 기기로 번갈아 플레이. 각 플레이어 베팅 전 '기기 전달' 가림막이 표시되어 상대 금액이 노출되지 않습니다.

## 규칙 요약

1. **BET** — 양측이 0~보유 칩만큼 비밀 베팅
2. **REVEAL** — 동시 공개. 높은 베팅이 착수권 획득, 동점은 타이브레이커 토큰 소지자가 승리 (토큰은 상대에게 이동)
3. **정산** — 승자는 자신의 베팅 칩을 패자에게 지급 (총량 200 고정). Bank 모드에서는 승자 칩이 소멸(은행 귀속)
4. **PLACE** — 승자가 빈 칸에 돌 1개 착수
5. **WIN** — 가로·세로·대각선 5연속 시 즉시 종료

보드 크기 11/13/15, 정산 모드(Classic/Bank)는 시작 화면에서 선택.

## 개발

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # dist/ (GitHub Pages 호환, base './')
```
